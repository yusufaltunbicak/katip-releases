# Katip for macOS

[Katip’i indir](https://github.com/yusufaltunbicak/katip-releases/releases/latest)

Apple Silicon (M serisi) işlemcili Mac ve macOS 15 veya üzeri gerekir.

1. Son sürümün DMG dosyasını indirin ve açın.
2. Katip’i Applications / Uygulamalar klasörüne sürükleyin.
3. Katip’i açın ve ekip yöneticinizden aldığınız lisans anahtarını girin.

İlk aktivasyon için internet bağlantısı gerekir. Her lisans bir Mac’te kullanılabilir. Aktivasyondan sonra en fazla 7 gün çevrimdışı kullanım sağlanır; devam etmek için lisansın internet üzerinden yeniden doğrulanması gerekir.

Lisans denetimi notları, ses kayıtlarını veya yapay zekâ sağlayıcılarının API anahtarlarını lisans sunucusuna göndermez. Yapay zekâ ve ses çözümleme sağlayıcısını kullanıcı seçer ve gereken API anahtarını kendisi girer.

Bu depo macOS kurulum paketlerini dağıtmak için kullanılır.
